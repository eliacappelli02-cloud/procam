# ProCam

Action cam per iPhone nel browser, con l'interfaccia dell'app Fotocamera di iOS: video, foto, raffica, time-lapse e registrazione in loop.

## Sviluppo

Serve Bun (https://bun.sh) oppure Node.js 20+.

```sh
bun install
npm run dev
```

Altri comandi: `npm run build`, `npm run preview`, `npm test`, `npm run lint`.

La fotocamera funziona solo in HTTPS (o su `localhost`).
